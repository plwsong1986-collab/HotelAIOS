# Components

**Project:** HotelAIOS  
**Module:** Website  
**Layer:** Components

---

# Purpose

The Components layer defines reusable website UI components shared across multiple pages and domains.

These components ensure visual consistency, improve maintainability, reduce duplicated implementation, and provide a standardized user experience throughout the website.

---

# Scope

This layer includes:

1. Component Overview
2. Navigation Components
3. Content Components
4. Booking Components
5. Form Components
6. Media Components
7. Feedback Components
8. Footer Components
