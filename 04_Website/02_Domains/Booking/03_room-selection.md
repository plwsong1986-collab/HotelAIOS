# Purpose

This document defines the structure and presentation requirements for the Room Selection page on the website.

The Room Selection page helps guests compare available accommodations after completing an availability search, enabling them to choose the room that best matches their travel needs before selecting a rate plan.

---

# Objectives

The Room Selection page should:

- Present available rooms clearly
- Support room comparison
- Help guests make informed decisions
- Provide a seamless transition to rate selection
- Maintain a consistent booking experience

---

# Page Structure

```text
Room Selection

├── Page Introduction
│
├── Available Rooms
│
├── Room Comparison
│
├── Selection Summary
│
└── Related Booking Pages
```

---

# Content Components

## Page Introduction

The introduction should:

- Explain the room selection process
- Encourage guests to compare available options
- Reflect the hotel's booking experience

---

## Available Rooms

Each available room may include:

- Room name
- Room image
- Short description
- Occupancy
- Bed configuration
- Room size
- Key amenities
- Starting price (when available)
- Availability status

Room information must reference the Knowledge module.

---

## Room Comparison

Guests should be able to compare available rooms using information such as:

- Room size
- Occupancy
- Bed type
- Included amenities
- View
- Accessibility features

Comparison information should remain consistent across all room pages.

---

## Selection Summary

After a room is selected, provide a summary including:

- Selected room
- Stay dates
- Guest information
- Selected occupancy
- Link to Rate Plans

Pricing and availability should be supplied by the booking system.

---

## Related Booking Pages

Provide links to:

- Booking Overview
- Availability Search
- Rate Plans
- Booking FAQ

Navigation should remain consistent throughout the booking journey.
