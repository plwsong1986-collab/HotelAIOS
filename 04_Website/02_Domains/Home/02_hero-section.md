# Purpose

This document defines the structure and content requirements of the homepage Hero Section.

The Hero Section is the first visual and informational area visitors encounter and should communicate the hotel's primary value clearly.

---

# Objectives

The Hero Section should:

- Create a strong first impression
- Communicate the hotel's identity
- Highlight the main guest value
- Guide users toward exploration
- Encourage booking actions

---

# Structure

```text
Hero Section

├── Primary Visual
│
├── Main Headline
│
├── Supporting Message
│
├── Primary Call-to-Action
│
└── Secondary Call-to-Action
```

---

# Content Components

## Primary Visual

The primary visual may include:

- Hotel exterior
- Signature spaces
- Guest experience scenes
- Destination imagery

Visual assets should follow Brand and Media standards.

---

## Main Headline

The headline should:

- Clearly communicate the hotel's positioning
- Reflect brand tone
- Remain concise
- Avoid generic statements

---

## Supporting Message

The supporting message should provide:

- Additional context
- Guest benefits
- Experience expectations

It should not duplicate detailed hotel descriptions.

---

## Primary Call-to-Action

The primary CTA should guide users toward the main conversion action.

Examples:

- Book Now
- Check Availability
- Explore Rooms

---

## Secondary Call-to-Action

Secondary actions may include:

- View Rooms
- Discover Experiences
- Explore Dining

---

# Content Ownership

| Content | Owner |
|---------|-------|
| Visual identity | Brand |
| Hotel facts | Knowledge |
| Page presentation | Website |
| Media assets | Media |

---

# User Experience Rules

The Hero Section should:

- Load quickly
- Remain readable on all devices
- Maintain clear visual hierarchy
- Avoid excessive information
- Provide immediate navigation options

---

# SEO Considerations

The Hero Section should support:

- Clear page relevance
- Primary keywords
- Proper heading hierarchy
- Accessible image descriptions

---

# Maintenance

Review the Hero Section when:

- Brand positioning changes
- Major visual assets are updated
- Homepage strategy changes
- Booking goals change
