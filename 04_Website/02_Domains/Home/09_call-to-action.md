# Purpose

This document defines the structure and implementation requirements for the Call To Action (CTA) sections on the homepage.

CTA elements guide visitors toward meaningful actions and support the website conversion goals.

---

# Objectives

The CTA section should:

- Guide users to the next step
- Support direct booking
- Reduce decision friction
- Improve user engagement
- Provide clear action paths

---

# CTA Structure

```text
Call To Action

├── Primary CTA
│
├── Secondary CTA
│
├── Supporting Message
│
└── Action Destination
```

---

# Content Components

## Primary CTA

The primary CTA represents the most important user action.

Examples:

- Book Now
- Check Availability
- Reserve Your Stay

The primary CTA should:

- Be visually clear
- Use direct language
- Appear at appropriate decision points

---

## Secondary CTA

Secondary CTAs support additional exploration.

Examples:

- Explore Rooms
- Discover Dining
- View Experiences
- Contact Us

---

## Supporting Message

Supporting messages may include:

- Guest benefits
- Reasons to choose the hotel
- Additional context

Messages should remain concise and consistent with Brand guidelines.

---

## Action Destination

Every CTA should connect to a clear destination.

Examples:

```text
Book Now
    ↓
Booking System

Explore Rooms
    ↓
Rooms Page

Discover Experiences
    ↓
Experiences Page
```

---

# CTA Principles

CTAs should:

- Use clear action language
- Avoid confusing choices
- Maintain consistent placement
- Support user intent
- Work across desktop and mobile devices

---

# Content Ownership

| Content | Owner |
|---------|-------|
| CTA strategy | Website |
| Brand wording | Brand |
| Destination information | Knowledge |
| Booking process | Operations / Booking System |

---

# User Experience Rules

CTA design should:

- Be easy to identify
- Provide immediate feedback
- Avoid excessive repetition
- Support natural user flow

---

# Maintenance

Review CTA elements when:

- Conversion goals change
- Booking processes change
- New website sections are introduced
- User behavior data indicates improvement opportunities
