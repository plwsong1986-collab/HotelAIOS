# Purpose

This document defines the structure and presentation requirements for the Room List page.

The Room List page presents all available room categories in a clear and organized format to help guests compare accommodation options.

---

# Objectives

The Room List page should:

- Display all available room categories
- Help guests compare room options
- Present key differences clearly
- Support room selection
- Guide users toward detailed room information and booking

---

# Page Structure

```text
Room List

├── Page Introduction
│
├── Room Category Cards
│
├── Comparison Information
│
└── Booking Call-to-Action
```

---

# Content Components

## Page Introduction

The introduction should:

- Explain the accommodation offering
- Reflect the hotel brand tone
- Help guests understand available choices

---

## Room Category Cards

Each room card may include:

- Room name
- Main image
- Short description
- Room size
- Guest capacity
- Key features
- Link to detail page

All room information must reference the Knowledge module.

---

## Comparison Information

The page may present:

- Room size differences
- Capacity differences
- Feature comparisons
- Suitable guest types

Comparison content should remain clear and avoid overwhelming users.

---

## Booking Call-to-Action

The page should provide actions such as:

- View Details
- Check Availability
- Book Now

# User Experience Rules

The Room List page should:

- Make comparison simple
- Maintain consistent room presentation

- Internal links to detail pages
