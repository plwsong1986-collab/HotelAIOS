# Purpose

This document defines the structure and presentation requirements for comparing room categories on the website.

The Room Comparison page helps guests evaluate accommodation options and select the room that best matches their needs.

---

# Objectives

The Room Comparison page should:

- Present room differences clearly
- Simplify decision-making
- Highlight guest benefits
- Support informed booking decisions
- Maintain consistent room presentation

---

# Page Structure

```text
Room Comparison

├── Comparison Introduction
│
├── Comparison Table
│
├── Feature Differences
│
├── Guest Recommendations
│
└── Booking Call-to-Action
```

---

# Content Components

## Comparison Introduction

Provide a brief explanation of how room categories differ and how guests can use the comparison.

---

## Comparison Table

The comparison table may include:

- Room category
- Room size
- Maximum occupancy
- Bed configuration
- View
- Key amenities
- Accessibility
- Link to room details

All factual information must reference the Knowledge module.

---

## Feature Differences

Highlight meaningful differences such as:

- Space
- Comfort
- Facilities
- Suitable guest types
- Premium features

Avoid repeating identical information across room categories.

---

## Guest Recommendations

Recommend suitable room categories for different guest needs.

Examples:

- Solo travelers
- Couples
- Families
- Business travelers
- Long stays

Recommendations should describe typical use cases rather than fixed rules.

---

## Booking Call-to-Action

Provide actions such as:

- View Room Details
- Check Availability
- Book Now
