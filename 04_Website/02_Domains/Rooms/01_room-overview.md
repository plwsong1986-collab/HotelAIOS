# Purpose

This document defines the overall presentation strategy for the Rooms overview page.

The page introduces the hotel's accommodation options and guides guests toward selecting suitable room types.

---

# Page Objectives

The Room Overview page should:

- Introduce available accommodation categories
- Help guests understand room differences
- Present key room benefits
- Support room exploration
- Guide users toward booking

---

# Page Structure

```text
Rooms Overview

├── Page Introduction
│
├── Room Categories
│
├── Room Highlights
│
├── Guest Benefits
│
└── Booking Call-to-Action
```

---

# Content Components

## Page Introduction

The introduction should:

- Present the overall accommodation experience
- Reflect the hotel brand tone
- Provide context before displaying room options

---

## Room Categories

Room categories should present:

- Room name
- Main image
- Short description
- Key features
- Capacity information
- Link to detail page

All room facts must reference the Knowledge module.

---

## Room Highlights

Highlights may include:

- Comfort features
- Space characteristics
- Design elements
- Guest experience benefits

---

## Guest Benefits

The page should communicate benefits such as:

- Suitable guest types
- Stay experience
- Convenience features
- Booking advantages

---

## Booking Call-to-Action

The page should provide clear actions:

Examples:

- View Room Details
- Check Availability
- Book Now

# User Experience Rules

The Room Overview page should:

- Make room selection easy
- Avoid unclear comparisons
- Present important information first
- Use consistent room terminology
- Support mobile browsing
