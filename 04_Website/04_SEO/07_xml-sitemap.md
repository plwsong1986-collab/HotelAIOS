# Purpose

This document defines the XML sitemap standards for the HotelAIOS website.

The XML sitemap helps search engines discover, crawl, and index important website pages while reflecting the current website architecture and content organization.

---

# Objectives

The XML Sitemap should:

- Improve page discovery
- Support efficient crawling
- Reflect website structure
- Exclude non-indexable pages
- Maintain sitemap accuracy
- Support long-term website scalability

---

# Sitemap Structure

```text
XML Sitemap

├── Homepage
│
├── Core Pages
│
├── Domain Pages
│
├── Blog Pages
│
├── Media Pages
│
├── Image Sitemap
│
├── Sitemap Index
│
└── Update Process
```

---

# Homepage

The homepage should:

- Always be included
- Represent the primary website entry point
- Use the preferred canonical URL
- Remain available for indexing

---

# Core Pages

Core pages should include:

- About
- Rooms
- Dining
- Facilities
- Experiences
- Services
- Booking
- Contact

Each page should have one canonical sitemap entry.

---

# Domain Pages

Domain pages should:

- Represent unique website content
- Follow the published URL structure
- Remain indexable
- Exclude duplicate versions

---

# Blog Pages

Blog pages should:

- Include published articles
- Exclude draft content
- Remove archived pages when appropriate
- Reflect current publication status

---

# Media Pages

Media-related pages should:

- Be included only when independently indexable
- Use canonical URLs
- Avoid duplicate entries

Media resources should remain associated with their parent content where applicable.

---

# Image Sitemap

Image sitemaps should:

- Include important visual assets
- Reference published images
- Support image discovery
- Remain synchronized with website content

---

# Sitemap Index

A sitemap index should:

- Reference all sitemap files
- Support website growth
- Maintain logical sitemap organization
- Reflect current sitemap availability

---

# Update Process

The sitemap should be updated when:

- New pages are published
- Existing pages are removed
- URLs change
- Page indexing status changes
- Website structure changes

Updates should occur automatically whenever possible.

---

# Quality Principles

The XML sitemap should:

- Include only canonical URLs
- Remain technically valid
- Avoid duplicate entries
- Reflect published content
- Remain synchronized with website architecture
- Support efficient crawling
