# Purpose

This document defines the metadata standards for the HotelAIOS website.

Metadata standards ensure consistent search presentation, improve click-through rates, support search engine understanding, and maintain a unified optimization strategy across all website pages.

---

# Objectives

The Metadata Standards should:

- Standardize page metadata
- Improve search result presentation
- Support search engine indexing
- Maintain consistent branding
- Reduce duplicated metadata

# Page Title

Every indexable page should define:

- One unique page title
- A clear primary topic
- Consistent brand naming
- Appropriate title length
- Human-readable wording

Page titles should accurately represent page content.

---

# Meta Description

Every indexable page should include:

- One unique description
- A concise page summary
- Clear user value
- Natural language
- Relevant keywords where appropriate

Descriptions should encourage search result engagement without misleading users.

---

# Canonical URL

Canonical URLs should:

- Identify the preferred page version
- Prevent duplicate indexing
- Match the published URL
- Remain stable over time

Only one canonical URL should exist for each page.

---

# Robots Directive

Robots directives should:

- Define indexing behavior
- Define link-following behavior
- Prevent indexing of restricted pages
- Remain consistent with indexing strategy

Robots directives should only restrict pages that provide no independent search value.

---

# Open Graph Metadata

Open Graph metadata should define:

- Title
- Description
- URL
- Content type
- Preview image
- Website name

Open Graph metadata should remain consistent with page content.

---

# Twitter Card Metadata

Twitter Card metadata should include:

- Title
- Description
- Preview image
- Card type

Metadata should provide a consistent appearance when shared on supported platforms.

---

# Language Metadata

Language metadata should:

- Define the page language
- Support multilingual implementations where applicable
- Align with page content
- Remain consistent across localized pages

---

# Social Preview Images

Preview images should:

- Represent page content accurately
- Follow brand guidelines
- Maintain consistent quality
- Support recommended dimensions
- Remain optimized for fast loading

---

# Metadata Quality Rules

Metadata should:

- Be unique
- Match visible content
- Avoid keyword stuffing
- Remain concise
- Be reviewed regularly
- Support user understanding
