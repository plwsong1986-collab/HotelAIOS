# Purpose

This document defines the metadata standards for the HotelAIOS website.

It establishes the principles, structure, governance, and ownership boundaries for page metadata to support search engines, AI systems, accessibility, and content management.

This document is the Single Source of Truth (SSOT) for website metadata standards.

---

# Overview

Metadata provides structured information describing website pages and content.

Consistent metadata improves discoverability, SEO, AI-assisted retrieval, content organization, and long-term maintainability.

This document defines metadata standards rather than implementation details.

---

# Scope

This document includes:

- Page metadata
- Metadata structure
- Metadata governance
- Canonical metadata
- Social metadata
- Structured metadata references
- Metadata lifecycle

This document does not include:

- SEO implementation
- Schema markup implementation
- Backend implementation
- Analytics configuration
- Frontend implementation

These remain owned by their corresponding modules.

---

# Metadata Principles

Metadata should be:

- Consistent
- Accurate
- Complete
- Machine-readable
- SEO Friendly
- AI Ready
- Reusable
- Easy to maintain

Metadata should accurately describe the associated content.

---

# Standard Metadata

Each page should support:

- Page Title
- Meta Description
- Canonical URL
- Page Language
- Author
- Publication Date
- Last Updated
- Keywords (where applicable)
- Open Graph Metadata
- Social Sharing Metadata

Additional metadata may be introduced while maintaining consistency.

---

# Metadata Governance

Metadata should:

- Follow standardized naming
- Remain synchronized with page content
- Avoid duplication
- Support multilingual content
- Support structured data
- Preserve canonical ownership

Metadata governance should be consistent across the website.

---

# Relationship with SEO

SEO consumes metadata defined by this document.

SEO implementation should extend these standards rather than redefine them.

---

# Relationship with Knowledge

Business knowledge remains owned by the Knowledge Module.

Metadata describes website content and should not redefine business knowledge.

---

Metadata should support:

- AI Assistants

Metadata should remain machine-readable and semantically consistent.
