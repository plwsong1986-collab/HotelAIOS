# Purpose

This document defines the hierarchical organization of all website pages within HotelAIOS.

It establishes the information architecture (IA), page relationships, structural hierarchy, and ownership boundaries that ensure a logical, scalable, and user-centered website.

This document is the Single Source of Truth (SSOT) for website page hierarchy.

---

# Overview

The Page Hierarchy defines how website pages are organized and connected.

It provides a consistent information architecture that supports navigation, user experience, SEO, accessibility, AI-assisted discovery, and future scalability.

This document defines page structure rather than page content.

---

# Scope

This document includes:

- Information Architecture (IA)
- Page hierarchy
- Parent-child relationships
- Page categorization
- Section organization
- Navigation hierarchy
- Structural governance

This document does not include:

- Individual page content
- UI implementation
- Component implementation
- CSS
- JavaScript
- SEO implementation

These remain owned by their corresponding components.

---

# Hierarchy Principles

The page hierarchy should follow these principles:

- Logical organization
- Predictable structure
- Consistent categorization
- Minimal navigation depth
- User-centered discovery
- Semantic organization
- Scalability
- Accessibility

The hierarchy should remain stable as the website evolves.

---

# Website Hierarchy

The primary website hierarchy consists of:

- Home
- Rooms
- Dining
- Experiences
- Facilities
- Services
- Guest Services
- Booking
- About
- Blog
- Contact

Additional sections may be introduced while maintaining architectural consistency.

---

# Parent-Child Relationships

Each page should belong to a clearly defined parent section.

Hierarchy should support:

- Top-level pages
- Category pages
- Detail pages
- Supporting pages
- Landing pages

Page ownership should remain unambiguous.

---

# Information Architecture

The information architecture should:

- Minimize navigation complexity
- Group related information
- Support intuitive exploration
- Reduce cognitive load
- Improve discoverability
- Support SEO
- Support AI retrieval

---

# Relationship with Navigation

Navigation implements the hierarchy defined by this document.

Navigation behavior should not redefine the website hierarchy.

---

# Relationship with Website Domains

Website Domains own the specifications of individual pages.

The Page Hierarchy defines how those pages are organized within the overall website architecture.
