# Purpose

This document is the authoritative reference for prompt reference standards within HotelAIOS.

It defines the structure, metadata, categorization, and governance of prompt references used by AI systems while remaining independent of specific prompt implementations.

This document is the Single Source of Truth (SSOT) for prompt reference standards.

---

# Overview

Prompt Reference provides standardized metadata for organizing and identifying prompt assets.

It establishes how prompts are classified, versioned, related to knowledge sources, and managed across the HotelAIOS Knowledge Architecture.

This document does not define prompt content or prompt engineering techniques.

---

# Scope

This document includes:

- Prompt classifications
- Prompt metadata
- Prompt identifiers
- Prompt ownership
- Prompt version references
- Prompt relationships
- Prompt governance

This document does not include:

- Prompt text
- Prompt engineering
- AI model behavior
- Business logic
- Knowledge content

These remain owned by the corresponding components.
