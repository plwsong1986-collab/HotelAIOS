# Purpose

This document is the authoritative reference for keyword indexing standards within HotelAIOS.

It defines the structure, organization, and governance of searchable keywords used across the HotelAIOS Knowledge Architecture.

This document is the Single Source of Truth (SSOT) for keyword indexing standards.

---

# Overview

The Keyword Index provides standardized keywords that improve semantic search, AI retrieval, document discovery, ontology mapping, and cross-domain consistency.

Keywords describe knowledge assets rather than replace their content.
