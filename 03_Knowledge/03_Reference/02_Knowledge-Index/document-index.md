# Purpose

This document is the authoritative reference for document indexing standards within HotelAIOS.

It defines the metadata structure, indexing rules, identification standards, and discovery mechanisms used to organize documentation across the HotelAIOS Knowledge Architecture.

This document is the Single Source of Truth (SSOT) for document indexing standards.

---

# Overview

The Document Index provides standardized metadata that enables documents to be uniquely identified, categorized, indexed, retrieved, and maintained.

It supports semantic search, AI retrieval, ontology integration, documentation governance, and cross-domain discoverability.

This document does not own document content.

# Standard Metadata

Each indexed document should include standardized metadata such as:

- Project
- Module
- Section
- Component
- Domain (when applicable)
- Document Name
- Version
- Status
- Last Updated
- SSOT Ownership

Additional metadata may be introduced while maintaining backward compatibility.
