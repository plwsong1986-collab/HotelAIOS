# Purpose

This document is the authoritative reference for entity indexing standards within HotelAIOS.

It defines how entities are uniquely identified, categorized, indexed, and referenced across the HotelAIOS Knowledge Architecture.

This document is the Single Source of Truth (SSOT) for entity indexing standards.

---

# Overview

The Entity Index provides a standardized structure for organizing entities used throughout the HotelAIOS knowledge ecosystem.

It enables semantic consistency, entity discovery, ontology integration, AI retrieval, and cross-domain interoperability.

This document defines entity indexing standards rather than entity content.

# Entity Classification

Entities may include:

- Destination
- Attraction
- Accommodation
- Facility
- Service
- Transportation
- Policy
- Room Type
- Amenity
- Cultural Asset
- Geographic Location
- Organization

Additional entity types may be introduced while maintaining backward compatibility.
