# Purpose

This document is the authoritative reference for taxonomy standards within HotelAIOS.

It defines the hierarchical classification model used to organize concepts, entities, and knowledge assets across the HotelAIOS Knowledge Architecture.

This document is the Single Source of Truth (SSOT) for taxonomy definitions.

---

# Overview

Taxonomy provides standardized hierarchical classifications that organize knowledge into logical structures.

It supports semantic search, AI retrieval, ontology consistency, knowledge navigation, and enterprise knowledge governance.

This document defines taxonomy standards rather than business knowledge.

---

# Scope

This document includes:

- Taxonomy definitions
- Classification hierarchy
- Parent-child relationships
- Category standards
- Semantic grouping
- Taxonomy metadata

This document does not include:

- Business knowledge
- Domain documentation
- AI implementation
- Database schemas
- Operational workflows

These remain owned by the corresponding components.

---

# Taxonomy Principles

Taxonomies should be:

- Hierarchical
- Stable
- Reusable
- Machine-readable
- Semantically consistent
- Implementation-independent

Every concept should belong to a clearly defined classification hierarchy.

---

# Taxonomy Structure

Typical taxonomy levels may include:

- Domain
- Category
- Subcategory
- Entity Type
- Entity
- Attribute

Projects may introduce additional levels while maintaining semantic consistency.

---

# Classification Rules

Taxonomy definitions should support:

- Parent category
- Child category
- Classification level
- Canonical name
- Metadata tags
- Ontology mappings

Classification rules should avoid duplicated hierarchies whenever possible.

---

# Standard Metadata

Each taxonomy node should support:

- Taxonomy identifier
- Canonical name
- Parent node
- Hierarchy level
- Description
- Metadata tags
- Related entities
