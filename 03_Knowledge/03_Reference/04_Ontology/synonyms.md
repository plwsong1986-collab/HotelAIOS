# Purpose

This document is the authoritative reference for synonym standards within HotelAIOS.

It defines how equivalent terms, aliases, abbreviations, and alternative expressions are represented consistently across the HotelAIOS Knowledge Architecture.

This document is the Single Source of Truth (SSOT) for synonym definitions.

---

# Overview

Synonyms provide semantic equivalence between different expressions that refer to the same concept.

They improve AI retrieval, semantic search, knowledge discovery, ontology consistency, and multilingual understanding.

This document defines synonym standards rather than business terminology.

# Synonym Principles

Synonyms should be:

- Canonical
- Stable
- Reusable
- Machine-readable
- Language-independent where possible
- Semantically equivalent

Every synonym should reference a single canonical term.

---

# Synonym Classification

Typical synonym types include:

- Exact Synonym
- Preferred Term
- Alternative Name
- Alias
- Abbreviation
- Acronym
- Common Expression
- Historical Name
- Regional Variant

Additional synonym types may be introduced while maintaining semantic consistency.
