# Purpose

This document is the authoritative reference for transportation classifications, terminology, and reusable metadata within HotelAIOS.

It standardizes transportation-related reference information shared across Knowledge Domains, AI Retrieval, Search, APIs, and Ontology components.

This document is the Single Source of Truth (SSOT) for transportation reference definitions.

---

# Overview

The Transportation Reference defines standardized classifications and terminology for transportation methods, services, and infrastructure.

It supports semantic consistency, metadata assignment, ontology modeling, AI retrieval, and enterprise-wide interoperability.

This document does not describe specific routes, schedules, fares, or destination transportation services.
