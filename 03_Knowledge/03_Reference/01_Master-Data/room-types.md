# Purpose

This document is the authoritative reference for room type classifications, terminology, and reusable metadata within HotelAIOS.

It standardizes room type reference information shared across Knowledge Domains, AI Retrieval, Search, APIs, and Ontology components.

This document is the Single Source of Truth (SSOT) for room type reference definitions.

---

# Overview

The Room Types Reference defines standardized classifications and terminology for accommodation room types.

It supports semantic consistency, metadata assignment, ontology modeling, AI retrieval, and enterprise-wide interoperability.

This document does not describe specific hotel rooms or property inventory.
