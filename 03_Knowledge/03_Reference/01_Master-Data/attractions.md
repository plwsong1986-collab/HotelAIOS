# Purpose

This document is the authoritative reference for attraction classifications, terminology, and reusable metadata within HotelAIOS.

It standardizes attraction-related reference information shared across Knowledge Domains, AI Retrieval, Search, and Ontology components.

This document is the Single Source of Truth (SSOT) for attraction reference definitions.

---

# Overview

The Attractions Reference defines standardized classifications and terminology for attractions.

It is intended for consistent indexing, metadata assignment, semantic search, ontology modeling, and AI retrieval.

This document does not describe individual attractions or destination-specific content.

---

# Scope

This document includes:

- Attraction classifications
- Attraction terminology
- Attraction metadata
- Attraction taxonomy
- Attraction reference definitions
- Shared attraction vocabulary

This document does not include:

- Destination guides
- Attraction descriptions
- Opening hours
- Pricing
- Ticketing
- Visitor recommendations
- Travel planning
- Commercial content

These remain owned by the corresponding Knowledge Domains.
