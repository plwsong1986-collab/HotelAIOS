# Purpose

This document is the authoritative reference for policy classifications, terminology, and reusable metadata within HotelAIOS.

It standardizes policy-related reference information shared across Knowledge Domains, AI Retrieval, Search, and Ontology components.

This document is the Single Source of Truth (SSOT) for policy reference definitions.

---

# Overview

The Policies Reference defines standardized classifications and terminology for policies used throughout the HotelAIOS knowledge ecosystem.

It supports semantic consistency, metadata assignment, AI retrieval, ontology modeling, and cross-domain interoperability.

This document does not contain destination-specific regulations, hotel policies, or operational procedures.
