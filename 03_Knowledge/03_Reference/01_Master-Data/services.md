# Purpose

This document is the authoritative reference for service classifications, terminology, and reusable metadata within HotelAIOS.

It standardizes service-related reference information shared across Knowledge Domains, AI Retrieval, Search, APIs, and Ontology components.

This document is the Single Source of Truth (SSOT) for service reference definitions.

---

# Overview

The Services Reference defines standardized classifications and terminology for services offered across hotels, destinations, and travel-related experiences.

It supports semantic consistency, metadata assignment, ontology modeling, AI retrieval, and enterprise-wide interoperability.

This document does not describe service availability, pricing, booking processes, or operational workflows.

---

# Scope

This document includes:

- Service classifications
- Service terminology
- Service metadata
- Service taxonomy
- Service reference definitions
- Shared service vocabulary

This document does not include:

- Service availability
- Service pricing
- Reservations
- Operational procedures
- Service delivery workflows
- Commercial promotions
- Property-specific information

These remain owned by the corresponding Knowledge Domains.
