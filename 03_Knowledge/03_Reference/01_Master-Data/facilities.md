# Purpose

This document is the authoritative reference for facility classifications, terminology, and reusable metadata within HotelAIOS.

It standardizes facility-related reference information shared across Knowledge Domains, AI Retrieval, Search, and Ontology components.

This document is the Single Source of Truth (SSOT) for facility reference definitions.

---

# Overview

The Facilities Reference defines standardized classifications and terminology for physical facilities and shared amenities.

It supports semantic consistency, metadata assignment, AI retrieval, ontology modeling, and enterprise-wide interoperability.

This document does not describe specific hotels, destinations, or individual facilities.
