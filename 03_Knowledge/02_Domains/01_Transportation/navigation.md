# Purpose

This document is the authoritative source for navigation information related to the hotel.

It provides factual guidance for guests using digital maps, navigation applications, and location services to find the hotel.

This document does not replace the official hotel location record or provide real-time navigation instructions.

---

# Overview

Accurate navigation information helps guests arrive smoothly, especially when traveling in unfamiliar destinations.

This document standardizes navigation-related information for AI assistants, websites, guest services, and operational reference.

Only stable and verifiable information should be maintained.
