# Purpose

This document is the authoritative source for room selection knowledge within the Rooms Domain.

It defines factual, implementation-independent information about the common factors guests consider when selecting a hotel room. The document supports AI assistants, guest services, concierge teams, reservation support, and other downstream systems through a Single Source of Truth (SSOT).

---

# Overview

Room selection is the process of identifying a room category that best matches a guest's accommodation requirements.

Guests may evaluate room options based on room type, occupancy, bed configuration, amenities, accessibility, location within the property, and other objective characteristics.

This document describes the common decision factors without providing booking recommendations or hotel-specific availability.

# Core Information

Common room selection factors may include:

| Factor | Description |
|---------|-------------|
| Room Type | Standard, Deluxe, Suite, Family Room, etc. |
| Occupancy | Maximum number of guests supported |
| Bed Configuration | Bed size and arrangement |
| Room Size | General accommodation space |
| Amenities | Available in-room facilities and equipment |
| Accessibility | Accessibility features where applicable |
| Room View | View category provided by the property |
| Floor Location | General location within the building |
| Intended Stay | Business, leisure, family, or extended stay |

Actual room availability and configurations depend on each property's official inventory.

# Accessibility

Room selection may involve accessibility considerations such as:

- Step-free access
- Wheelchair-accessible layouts
- Accessible bathrooms
- Hearing or visual accessibility features
- Elevator access where applicable

Accessibility requirements should be evaluated using the property's official accessibility information.
