# Purpose

This document is the authoritative source for room type knowledge within the Rooms Domain.

It defines factual, implementation-independent information about hotel room classifications, their common characteristics, and naming conventions. The document supports AI assistants, guest services, concierge teams, booking guidance, and other downstream systems through a Single Source of Truth (SSOT).

---

# Overview

Room types classify guest accommodations according to factors such as size, layout, occupancy, facilities, and intended use.

Although terminology may vary between hotels and brands, many room type classifications are widely recognized across the hospitality industry.

This document records stable knowledge about room classifications without describing individual hotel inventory or availability.

# Core Information

Typical room classifications may include:

| Room Type | General Description |
|------------|---------------------|
| Standard Room | Basic guest room with essential accommodations |
| Superior Room | Enhanced room with additional space or features |
| Deluxe Room | Higher-category room with upgraded comfort |
| Executive Room | Room designed primarily for business travelers |
| Studio | Open-plan room combining sleeping and living areas |
| Suite | Accommodation with separate functional living spaces |
| Family Room | Room designed for families or larger groups |
| Accessible Room | Room designed to improve accessibility for guests with disabilities |
| Connecting Room | Rooms linked by an internal connecting door |

Actual room categories depend on each property's official classification.
