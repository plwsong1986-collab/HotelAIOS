# Purpose

This document defines the official terminology used throughout the HotelAIOS Knowledge module.

It serves as the **Single Source of Truth (SSOT)** for terminology to ensure consistent language across documentation, AI systems, websites, OTA platforms, operational materials, and future project modules.

This glossary defines terminology only.

It does not replace the detailed documentation maintained in other Knowledge documents.

---

# Overview

Consistent terminology improves communication, documentation quality, AI responses, and system interoperability.

Every official concept used within HotelAIOS should have a single preferred term and definition.

Whenever possible, terminology should reference the document that owns the concept.

---

# Scope

This glossary standardizes terminology related to:

- Hotel information
- Location
- Rooms
- Facilities
- Services
- Experiences
- Policies
- General operational vocabulary

Brand messaging, tone of voice, slogans, and marketing language belong to the **Brand** module.
