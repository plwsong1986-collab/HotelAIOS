# Purpose

This module contains the official brand documentation for HotelAIOS.

It serves as the **Single Source of Truth (SSOT)** for the identity, philosophy, voice, messaging, and communication standards of **Sanlitian Oxygen Boutique Guesthouse**.

All public-facing content—including websites, AI interactions, OTA listings, marketing materials, media assets, and future communication channels—should follow the standards defined in this module.

This module defines the brand.

It does **not** define operational processes, software implementation, technical architecture, or website implementation.

---

# Module Scope

This module owns the following areas:

- Brand philosophy
- Brand identity
- Brand story
- Core values
- Brand voice
- Guest promise
- Storytelling
- Messaging and taglines
- Visual direction

This module does **not** own:

- Business operations
- Knowledge management
- Website implementation
- AI implementation
- Software development
- Infrastructure and deployment
- Operational procedures

# Ownership

Each document owns one specific responsibility.

Do not duplicate concepts across multiple documents.

Examples:

- Brand philosophy belongs in **01_brand-manifesto.md**.
- Brand story belongs in **02_brand-story.md**.
- Core values belong in **03_core-values.md**.
- Brand voice belongs in **04_brand-voice.md**.
- Guest experience belongs in **05_guest-promise.md**.
- Official messaging belongs in **08_taglines.md**.

When information already exists, reference the authoritative document instead of rewriting it.
